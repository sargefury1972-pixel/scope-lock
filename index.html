What a match proves

If the fingerprints match, this exact agreement text, including both names and confirmation times, existed no later than the block time of that transaction. The BSV network sets the block time, so it can't be back-dated.

Change one character, such as a price, a comma or a name, and the fingerprint won't match. Line endings and trailing spaces are ignored, so copying between apps is safe.

Check it without this site

Save the agreement text as a UTF-8 file with no final newline and run shasum -a 256 on it. Then compare the result with the 32 bytes after “SCOPELOCK” “1” in the transaction's OP_RETURN output on any BSV explorer.

How much to put on it?

Each lock costs about 31 satoshis in network fees.

100,000 sats (0.001 BSV) covers about 3,000 locks and is worth about 1–2p.

Send from any BSV wallet, such as HandCash, Yours, RockWallet or an exchange. Only send BSV, not BTC or BCH.

Privacy

Agreements are kept in this browser and in the links you choose to send. They are never uploaded. Only the fingerprint, the public title and the lock time go on the blockchain. Balance lookups and broadcasts go to WhatsOnChain and GorillaPool ARC.
